# Bahar-e-Shariat Easy Roman Urdu Glossary

Record approved spellings and wording decisions here before reusing them across batches.

| Source term | Approved Roman Urdu | Notes |
|---|---|---|
| انبیاء | Ambiya | Use consistently |
| اُنہوں نے / انہوں نے | unhone | Natural Roman Urdu spelling |
| رضی الله تعالی عنہ | رضی الله تعالی عنہ | Preserve in Arabic |
| ﷺ | ﷺ | Preserve exactly |
| حلول (hulool) | kisi cheez ke andar sama jana | Use in explanatory prose |
| تعدد (ta'addud) | ek se zyada hona | Use in explanatory prose |
| کلی (kulli) | badi ya poori cheez | Choose the natural meaning from context |
| جزوی (juzwi) | chhoti ya kisi ek cheez se muta'alliq | Choose the natural meaning from context |
| معلق (mu'allaq) | kisi shart ke saath rakha hua | Use the full explanatory phrase in manuscript |
| تعلیق (ta'leeq) | kisi shart ke saath hona | Avoid the technical term in reader-facing prose |
| گہوارہ | jhula | Use the easier word instead of gahwara/gahware |
| متوسلین | in se jure hue sab logon | Use when referring to people connected with Aal-o-Ashab, Muhajireen, and Ansar |
| عِلِّيِّين | Illiyyeen (bahut buland aur ba-izzat maqam) | Explain the difficult word in brackets on first use |
| قفس | qafas (pinjre) | Keep the literary word and add the easy meaning in brackets |
| ہمُوار | seedhi | Use in the description of the Hashr ground |
| چابک کا سِرا | koore ka agla hissa | Use the easy explanation instead of chabuk ka sirah |
| صلیب | Saleeb | Romanize in reader-facing prose |
| خنزیر | khinzeer | Correct Roman Urdu spelling for pig |
| عذاب و تنعیمِ قبر | qabr ke azaab aur aaraam | Use the easier wording in reader-facing prose |
| متعلّقین | apne logon | Use in the context of people receiving Shafa'at |
| يا محمد | Aye Muhammad ﷺ | Use `Aye` rather than `O` for vocative address |
| بلوغ | baligh hona | Use `baligh hone se pehle` in easy reader-facing prose |
| تقلید | kisi alim ki baat maan kar amal karna | Retain as `taqleed` and explain it in brackets on first use; avoid `blind following` |
| کراماً کاتبین | aamaal likhne wale farishte | Use the easy wording instead of `Kiraman Katibeen` in reader-facing prose |
| گارا | gaarah (eenton ko jorne wala lep) | Explain this difficult word in brackets on first use |
| قشقہ | maathe par tilak lagana | Use the clear meaning instead of `Qashqah lagana` |
