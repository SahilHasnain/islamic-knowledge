# Tadbir-e-Falah, Najat aur Islah

Dedicated editions of `تَدْبِيرُ فَلَاحٍ وَنَجَاتٍ وَإِصْلَاحٍ` from Fatawa Razaviyyah,
volume 15, beginning at printed page 142.

- `english/`: standard faithful English translation
- `easy-roman-urdu/`: easy-language Roman Urdu adaptation
- `source/`: exact extracted source records from `db/fatawa_e_razvia.db`
