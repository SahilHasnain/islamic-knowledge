# Translation Plan

## Pehla batch

Is batch mein JSON order ke pehle paanch kalam mukammal kiye jayenge:

1. `001 meri-nawa-e-shauk` - 5 band
2. `002 agar-kaj-ro-hain-anjum-asman-tera-hai-ya-mera` - 5 band
3. `003 tere-shishe-mein-mai-baqi-nahin-hai` - 2 band
4. `004 gaisu-e-tabdar-ko-aur-bhi-tabdar-kar` - 7 band
5. `005 asar-kare-na-kare-sun-to-le-meri-faryad` - 7 band

## Har entry ka format

- Kalam number aur slug
- JSON title aur source URL
- Preserved Roman Urdu kalam
- Har stanza ka alag heading aur Easy Roman Urdu Explanation
- Aakhir mein Markazi Paigham

## Verification

- JSON ke slug, title, URL aur transliteration se muqabla.
- Har band ki line order aur khaali line wali boundary ki jaanch.
- Explanation mein tamam imagery, mushkil lafz aur bunyadi falsafiyana ishara cover karna.
- Roman Urdu mein ghair-zaroori English plural `-s`, Devanagari aur Urdu prose se parhez.
- File 1,000 lines se kam rakhna.
