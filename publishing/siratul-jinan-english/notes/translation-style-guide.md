# Sirat-ul-Jinan Standard English Style Guide

## Translation Method

- Translate the complete Sirat-ul-Jinan source faithfully into standard English.
- Do not summarize, omit, merge away, modernize away, or add independent commentary.
- Preserve every explanation, ruling, example, quotation, citation, footnote, and source boundary.
- Retain the author's scholarly and devotional tone.

## Quran and Arabic

- Preserve Quranic Arabic, Arabic duas, complete Arabic quotations, citations, and established
  honorifics exactly as supplied by QuranDB.
- Use the English Kanz-ul-Iman translation from QuranDB's `translation` table where
  `language_code='en'` and `trans_type='3'`. Do not use the Easy Roman Urdu project's
  transliterated translation or the English Kanz-ul-Irfan row (`trans_type='8'`).
- Preserve `ﷺ` wherever it occurs.

## Adab

- Use reverent English for the Prophet ﷺ, Ambiya, Sahaba, Ahl-e-Bait, and scholars.
- Never use “died” or “death” directly for the Prophet ﷺ. Use “passed away,” “departed,” or
  “was called back.”
- Never use diminishing wording such as “no more than” for the Prophet ﷺ.
- Render `قُلْ` and similar vocatives reverently, such as “Say (O Beloved)” or “O Prophet.”
- Render `اُمّی` for the Final Prophet as “unschooled,” never “unlettered.”

## Review

- Verify every batch for complete source coverage, ordering, meaning, Arabic preservation,
  citations, honorifics, adab, and accidental omissions.
- Translate shers and poems with deliberate attention to radif (refrain) and qafiyah (rhyme),
  preserving their poetic form rather than rendering them as plain prose.
- Keep each manuscript file below 1,000 lines and split only at complete entry boundaries.
