# Editorial Decisions

## Initial Decision

- **Source**: `content/books/shifa-shareef.json`, the existing Roman Urdu edition.
- **Method**: Manual retranslation into easy Roman Urdu, not script conversion and not summarization.
- **Arabic**: Preserve Quranic Arabic, Arabic duas, Arabic quotations, Arabic honorifics, and `ﷺ` exactly.
- **Architecture**: One Markdown file per baab; each fasl remains an internal section.
- **Scope**: The Hindi project is paused and remains unchanged. This is a separate edition.

## Approved Simplification Pattern

- Simplify difficult vocabulary and sentence structure, but preserve source phrases that carry adab or a specific religious meaning.
- Preserve phrases such as `haibate kalaam` and `sharaite muhabbat`; simplify only the surrounding wording where needed.
- Use easy wording such as `phat jaata` for `shaqq ho jaata` when the meaning remains exact.
- Use `apni jaan par khel jaoge` for this source expression; do not replace it with `apni jaan khatam kar doge`.
- Use `marte dam tak` instead of `maut aane tak` in this passage.
- Check every edited sentence against the literal Roman Urdu source before finalizing it.
