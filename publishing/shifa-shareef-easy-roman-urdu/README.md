# Shifa Shareef — Easy Roman Urdu

This edition rewrites the existing Roman Urdu source in simple, readable Roman Urdu.

It is not a summary and not a Devanagari transliteration. The meaning, reverence, references, and complete content must be preserved.

Source of truth: `content/books/shifa-shareef.json`.

Manuscript files use one file per baab. Each fasl remains a section inside its baab file.

The `00-pilot/` directory is only for temporary style experiments. Approved files are promoted to `manuscript/` before the full book is continued.
